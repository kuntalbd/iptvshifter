# Project Structure — M3U Playlist Processor v1.2

> Read this first. It explains what every folder/file is, which one is the
> ACTUAL source code, and which are safe to delete.

## TL;DR
- **The app = `src/m3u_processor/`** (one Python package, ~2,300 LOC).
- **Required to run:** `src/m3u_processor/` + `pyproject.toml` (for the
  `m3u-processor` command). Without `pyproject.toml` you can still run
  `python -m m3u_processor ...` directly.
- **Everything else is optional** (tests, specs, samples, scripts, logs,
  build artifacts). Deleting them does NOT break the app.

## The source package — `src/m3u_processor/` (KEEP)

| File | Responsibility |
|------|----------------|
| `__init__.py` | Package version (`__version__ = "1.2.0"`). |
| `__main__.py` | **CLI entry point.** `m3u-processor run/serve/init-db/generate-output/...` (§9). |
| `config.py` | Load config with precedence: CLI > env (`M3U_*`) > `config.yaml` > defaults (§18.4). |
| `database.py` | SQLite schema, pragmas (WAL etc), backup/gzip, migrations (§19). |
| `models.py` | `Stream`, `Provider`, `Run` dataclasses. |
| `parser.py` | Playlist parsing: 3 header syntaxes (#EXTVLCOPT/#EXTHTTP/#KODIPROP), pipe, normalization, winner/multi-token dedupe, `merge_into_db`. |
| `validator.py` | **Validation engine.** Scheme branch (F4), embedded headers (F1), HEAD→GET, retry/backoff, per-host semaphore, 403→`suspected_expired` (C1). |
| `blacklist.py` | Tiered blacklist state machine (none→short→permanent), F26 never-worked→permanent, purge. |
| `providers.py` | Provider aggregation + enable/disable. |
| `orchestrator.py` | **Run flow.** 3 modes (quick/regular/full), checkpointing, stale-token re-extract (C1), signals, `_eligible_rows`, `_row_to_stream`. |
| `writers.py` | Multi-format output: `working.m3u` (VLC), `working.kodi.m3u` (Kodi), `working.tivimate.m3u` (TiviMate) (§7.1, F13–F22). |
| `categorize.py` | Normalize stream groups into a small taxonomy (genre>country); drives single-file categorized output. |
| `deploy.py` | Generate systemd unit files with Pi hardening (§22). |
| `webui/app.py` | **FastAPI app** — 6 pages + JSON APIs + SSE event stream (§11). |
| `webui/templates/` | Jinja2 templates: base, dashboard, streams, providers, blacklist, run, settings. |
| `webui/static/style.css` | Vendored (no CDN) dark dashboard CSS. |

## Minimal portable copy
If you want to ship just the app, copy these two and nothing else:
```
src/m3u_processor/   +   pyp
```
(`pyproject.toml` for the `m3u-processor` command; drop it if you only run
`python -m m3u_processor`).

## How to run (after keeping the source)
```bash
pip install -e .                       # installs `m3u-processor` command
cp config.yaml.example config.yaml     # edit DB path / feeds
m3u-processor init-db
m3u-processor run --mode regular
m3u-processor generate-output --formats vlc,kodi,tivimate
m3u-processor serve --host 0.0.0.0 --port 50152
```
Or without install: `python -m m3u_processor run --mode regular`.
